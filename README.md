# Minji Desktop Pet

Minji 是一只清爽学院风的 Q 版桌宠。这一版的思考动作是六帧托腮循环：托腮、轻点下巴、短暂眨眼，再自然回到起始姿势；没有电脑、键盘或敲击手势。

![Minji 思考动作](thinking-preview.gif)

## 文件

- `spritesheet.webp`：ChatGPT Pets v2 图集，1536 × 2288
- `pet.json`：桌宠元数据
- `thinking-preview.gif`：思考动作预览
- `thinking-stills.png`：思考动作关键帧
- `Minji-thinking-update.zip`：包含完整预览、QA 报告、源图与提示词的归档包

最终图集已通过结构、透明背景、必需帧、动作连续性及 ChatGPT Pets 上传前校验。
